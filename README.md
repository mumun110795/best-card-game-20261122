# EMBERFALL — Duel of the Four Sparks

An original two-player card duel for the browser. You are the Sparkbearer (20 life) against the Ashen Warden (22 life): spend ember on cards from four suits — Flame, Tide, Thorn and Gloom — chain matching suits to Kindle bonus effects, and read the Warden's telegraphed intent to counter its next play. Static files under `game/` (vanilla JS, no build step, no network); `main.ts` hands the game in with the kit's dossier builder.
